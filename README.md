## Featured project

### [Enterprise RAG Evals](docs/projects/enterprise-rag-evals.md)

**Estado:** diseño aprobado · implementación siguiente

Un sistema documental en español que ingiere información, recupera evidencia, responde con citas y mide cuándo debe negarse a contestar. El proyecto está pensado para demostrar ingeniería de backend, retrieval, evaluación, observabilidad y seguridad.

## What I prove

- Diseñar una solución a partir de un problema operativo concreto.
- Preparar datos estructurados y no estructurados para un sistema de IA.
- Exponer capacidades mediante APIs tipadas y reproducibles.
- Comparar una baseline con retrieval semántico o híbrido.
- Evaluar calidad, groundedness, rechazo seguro, latencia y coste.
- Integrar herramientas y modelos sin ocultar sus límites.
- Añadir logs, trazas, permisos, validación de entradas y manejo de fallos.
- Documentar qué está simulado, qué está verificado localmente y qué no está desplegado.

## Working principles

- Una demo bonita no sustituye a una evaluación reproducible.
- Un modelo conectado no es una integración de producción.
- Cada métrica necesita un dataset, un comando y una limitación documentada.
- Los datos públicos o sintéticos son suficientes para demostrar la arquitectura sin exponer información privada.

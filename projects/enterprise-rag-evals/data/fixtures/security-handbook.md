# Manual sintético de seguridad de Acme Norte

Este documento es material de demostración creado para Enterprise RAG Evals. No contiene datos de clientes ni procedimientos reales.

## Retención de evidencias

Las evidencias de un incidente de seguridad deben conservarse durante 30 días desde el cierre del incidente. El responsable debe registrar el identificador del caso, el alcance revisado y la fecha de eliminación prevista.

## Comunicación de un incidente

La primera comunicación debe describir hechos confirmados, impacto conocido y acciones ya ejecutadas. No se deben afirmar causas que todavía no estén verificadas. Si falta evidencia, se debe marcar la respuesta como pendiente de investigación.

## Acceso de emergencia

El acceso de emergencia requiere aprobación de una persona responsable y una caducidad explícita. Al terminar la intervención se deben revocar los permisos temporales y dejar una nota de auditoría.
